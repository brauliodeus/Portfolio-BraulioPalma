# Portfolio Braulio Palma

Bienvenido a mi portafolio personal. Este proyecto es una aplicación web diseñada para mostrar mis proyectos, habilidades y experiencia profesional. Cuenta con un panel de administración (dashboard) que permite gestionar dinámicamente el contenido.

## 🚀 Características

*   **Página Principal:** Exhibición de proyectos y perfil personal.
*   **Panel de Administración (Dashboard):** Interfaz segura para agregar, editar o eliminar proyectos.
*   **Gestión Dinámica:** Integración con base de datos MySQL para cargar contenido en tiempo real usando AJAX.
*   **Diseño Responsivo:** Adaptado para funcionar tanto en computadoras de escritorio como en dispositivos móviles.

## 🛠️ Tecnologías Utilizadas

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Bootstrap.
*   **Backend:** PHP.
*   **Base de Datos:** MySQL.

## ⚙️ Instalación y Configuración Local

Si deseas correr este proyecto en tu entorno local, sigue estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/brauliodeus/Portfolio-BraulioPalma.git
    ```
2.  **Mover al servidor local:**
    Asegúrate de colocar la carpeta del proyecto en el directorio correspondiente de tu servidor local (ej. `htdocs` si usas XAMPP).
3.  **Base de Datos:**
    *   Abre phpMyAdmin (o tu gestor de base de datos preferido).
    *   Crea una base de datos nueva (ej. `portfolio_db`).
    *   Importa el archivo `database.sql` que se encuentra en la raíz del proyecto.
4.  **Configuración de Conexión:**
    Si es necesario, actualiza las credenciales de la base de datos en los archivos de conexión (generalmente dentro de la carpeta `includes` o `api`).
